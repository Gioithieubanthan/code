Giải thích Thuật Toán VLSM

VLSM (Variable Length Subnet Mask) là kỹ thuật chia mạng con với mặt nạ độ dài linh hoạt, cho phép tối ưu hóa việc sử dụng địa chỉ IPv4 và hạn chế tối đa lãng phí không gian địa chỉ.

  • Bước 1: Sắp xếp giảm dần: Sắp xếp các phòng ban theo nhu cầu Host giảm dần (từ phòng lớn nhất đến nhỏ nhất). Đây là nguyên tắc bắt buộc của VLSM.
  • Bước 2: Tính số bit Host (n): Tìm số bit n nhỏ nhất thỏa mãn công thức 2n - 2 ≥ Số Host yêu cầu. (Đã tính thêm 2 địa chỉ bắt buộc dành riêng cho Network ID và Broadcast ID).
  • Bước 3: Xác định Prefix (/CIDR): Prefix mạng con mới = 32 - n. Subnet Mask tương ứng được chuyển đổi từ 32 - n bit 1 liên tiếp.
  • Bước 4: Xác định Block Size: Kích thước dải IP Block Size = 2n. Địa chỉ Broadcast = Network IP + Block Size - 1.
  • Bước 5: Chuyển sang subnet tiếp theo: Địa chỉ Network IP của subnet kế tiếp = Broadcast IP hiện tại + 1.

Hướng Dẫn Sử Dụng & Tính Năng

1
Nhập dải IP mạng ban đầu: Điền Network IP và Prefix chính (ví dụ: 192.168.1.0/24 hoặc 10.0.0.0/16).
2
Quản lý danh sách phòng ban:
  • Nhấn "Thêm phòng ban" để tạo phân vùng mạng mới.
  • Chỉnh sửa trực tiếp Tên phòng hoặc Số host ngay trên từng ô nhập liệu.
  • Nhấn nút Kick / Xóa màu đỏ để loại bỏ 1 phòng cụ thể.
  • Nút "Xóa tất cả" dùng để xóa sạch toàn bộ danh sách phòng ban.
3
Tự động chia & tính toán lại: Bất kỳ thao tác thêm, sửa, Kick/Xóa hay thay đổi dải IP đều kích hoạt tính toán lại VLSM ngay lập tức mà không cần bấm thêm nút.
